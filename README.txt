SILVER TOWER HERO COMPANION — iPAD PLAYTEST

1. Open index.html in Safari from a web host or the supplied ChatGPT download link.
2. In Safari, tap Share > Add to Home Screen.
3. The app saves progress locally in Safari storage on that iPad.
4. Use Campaign > Export Backup before clearing Safari history/data.

This is a single-device test build. Multiplayer synchronization is not included yet.
